# PR #78: M16A4 optic slot: Red dot, CompM2, ACOG at the Loadmaster (merit-only unlocks)

- Author: MatthewDuke04 (Nova) (branch `nova/m16a4-optic-slot`)
- Head commit reviewed: `3e295dbcc9cd5ff39ebf40f27bdeaeca38e7fd6a`
- Reviewed: 2026-11-18 (by reading the code; the tests were not run here)

**Verdict: Fix first** (one small fix so a saved loadout cannot be wiped; it also needs a
rebase on main and conflicts heavily with #80).

## What it does

The M16A4 (the service rifle) gets a sight slot. At the Loadmaster's EDIT screen you can buy
(with merits only) and fit a red dot, a CompM2 or an ACOG; in a match the sight changes how
far you zoom when aiming and how fast you get into the sights, and the ACOG lowers kick.

## Findings

1. **Fitting a sight while your saved loadout is still loading wipes that loadout** (sure by
   reading). `LoadmasterService.fit` starts from the signed loadout, or the default one if none
   is signed yet (`src/lobby/server/LoadmasterService.luau:85`), signs and saves it. When the
   saved loadout then finishes loading, `load` sees one is already signed and keeps it
   (lines 50-60), so the stored guns, call-ins and suppressor are lost, and the default is saved
   over them. Trigger: join the lobby when the save service is slow and fit a sight straight
   away. Smallest fix: refuse `fit` with "loading" until this player's load has finished (a
   `loaded[player]` flag set at the end of `load`).
2. **The match does not check you bought the sight** (sure; small impact). The match checks a
   loadout only against the list of items that exist (`LoadoutService.luau:481`,
   `HandoffService`), not against what the soldier owns. A hacked client could fit an ACOG
   for free. The effect is only on that player's own camera, which a hacker could change
   anyway, and unowned guns already slip through the same way. Accept it and write it in
   `docs/LOBBY_MATCH_HANDOFF.md`, or have the match check the soldier's record, which it already
   reads for merits.
3. **Publish order** (possible, a deploy trap). If the lobby with sights goes live while the
   match is still the old build, the old match does not know the sight slot, rejects the whole
   loadout and gives that player the default kit: they lose their guns, not only the sight.
   Publish the match first, or make the match drop unknown attachment slots instead of the whole
   loadout.
4. Rules question for Tien: which guns take a sight is a list on each sight's Config row
   (`Guns = { "service_rifle" }`, `src/shared/Config.luau:147, 156, 165`). The suppressor does
   it the other way, with a flag on the gun's own row. The project rule prefers the gun's row,
   so adding a sight slot to another gun would mean editing every sight row.
5. **Clash with #80**: both rewrite the same lobby buy function in `RecordService` (this PR adds
   `purchase`/`buyWith`, #80 adds a general `RecordService.change`). Whichever merges second
   should use the other's version. Git also reports conflicts in `Messages.luau`,
   `Remotes.luau`, the lobby `Main.server.luau`, `GunsmithUI.luau` and docs; several of those
   also conflict with main already.
6. Small: some refusal reasons (`"attachments"`, `"primary"`, `"not on record"`) show only a raw
   "Refused (x)" in the Gunsmith; two quick BUY clicks answer "record still loading" (#80
   uses "busy"); `AttachmentRules.luau:10` is the only `require("./Record")` string-style
   require in `src/`; the sight's "time to aim" also slows leaving the sights, but the docs only
   say "into the sights".

Fine: buying a sight uses the same safe save path as other buys (the merit race fixed in #60
stays fixed); old saves read fine (sights are just more ids in `owned`); the lobby server checks
every argument type, that the sight exists, fits that gun and is owned, before fitting; the zoom
always returns to normal when you stop aiming, die, reload or switch guns; new rules have tests.

## Check in Studio

1. Match with an ACOG fitted: aim in first and third person (about 4x zoom); stop aiming, die
   while aiming, reload while aiming: the view goes back to normal each time.
2. Switch to the pistol while aiming: no sight zoom on the pistol.
3. Lobby: sign a custom loadout, rejoin, fit a sight at once, rejoin again: are your guns and
   call-ins still there (finding 1)?
4. Click BUY on two sights quickly: only one charge.
