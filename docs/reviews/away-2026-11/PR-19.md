## What it does

It adds a Blender script (`assets/3d/build/infected_roster.py`) with looks for five Infected
that are not in the game yet: Bloat, Shedder, Crawler, Kite and Growth, in the same style as
the remade four, with preview pictures and a line-up of all nine. Nothing in the game changes.

## Findings

1. Fine: no file under `src/` or `tests/` changes. The meshes are only built when the asset
   build is run with `--infected-roster`; nothing is exported or uploaded.

2. **The author's own notes say two forms are not ready.** The Shedder "still reads a
   little like plate armour" and the Kite is weak from the front (handoff note and
   `docs/BACKLOG.md` in #29). The Kite and Growth sit exactly on their triangle limits
   (600 and 1,200), so there is no room to add detail.

3. **Each form needs a design decision before it can go in the game**, which this proposal
   does not make: the Crawler's height and animation, how the Kite moves, the Growth's sacs
   as spawners. Approving a look here does not approve those.

4. It is built on #17's branch, so it contains #17's files too. If #24 merges first, this
   will need a small merge in `build_assets.py` and `docs/STYLES.md`.

5. Size: about 16 MB of preview pictures (including #17's 7 MB).
