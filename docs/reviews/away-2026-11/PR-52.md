- Author: MatthewDuke04 (Nova; branch `nova/mile14`)

- Reviewed: 2026-11-12 (by reading the code; the tests were not run here). Only Nova's five
  new commits were reviewed (`5b285c5..da353d3`, 56 files, about 2,000 lines).

**Verdict: Fix first** (five features in one pull request; the cheat checks are sound and
Checkpoint Delta's difficulty is unchanged, but there is a slow leak that reaches Delta, a
bot change that reaches Delta, and Mile 14 itself cannot be finished properly yet. It also
targets `main` with #48, #49, #50 and the integration branch inside.)

## What it does

1. A second mission place, **Mile 14** (a highway, buses, toll booths, woods, a near-black
   night), with its own Rojo project file.
2. **Infected awareness**, on Mile 14 only: Infected sleep, stand idle or wander until they
   see or hear the squad (shots, explosions, running), then search and chase.
3. A **suppressor** you fit to a gun on a new EDIT screen at the lobby's Loadmaster; shots
   with it are heard from much less far away.
4. **Bots spread out** in a loose ring round their leader, on every mission.

## Findings

1. **Do not press Merge on this by itself.** Against `main` it is 96 commits: the
   integration branch (#44), then Nova's #48, #49, #50, then these five.

2. **A list that grows forever, on Checkpoint Delta too.** Every Infected that spawns is
   added to a "do not look through these" list for sight checks
   (`src/server/EnemyService.luau:167-168`, `:623`, `lookParams:AddToFilter(model)`), on
   every mission, and nothing ever removes entries: not death, not a run restart. A server
   that runs many missions keeps hundreds, then thousands, of dead entries.
   How sure: verified by reading (the list is only *used* on Mile 14, but it *grows* on
   Delta). Smallest fix: only add when awareness is on, and empty the list in
   `EnemyService.clearAll()`.

3. **A Mile 14 run uses Checkpoint Delta's objective, boss and landing positions.** The
   Mile 14 file (`src/server/Missions/Mile14.luau`) only builds the scenery. There is no
   objective list for it (`Config.Objectives.Maps` has no `mile14`), so the game falls back
   to the old single hold at Delta's coordinates (50, 8.5, 50), which on this map is a slab
   cutting into the road embankment; the Warden spawns at Delta's gate position and walks
   Delta's route; the landing zone is Delta's.
   How sure: the coordinates are verified; what it looks like in game is not. The run can
   probably start; whether it can be finished is doubtful. Nova's docs say "Not yet:
   objectives". Nothing in the lobby launches into Mile 14 yet, so players cannot reach it.

4. **Mile 14 spawns about 70 Infected at once, above the game's own limit of 44.**
   `src/shared/Config.luau:154` (`Count = 70`), all created in one frame 1.5 s after the
   mission starts (`EnemyService.luau`, `populate`). The limit
   (`Config.Difficulty.MaxAliveHardCap = 44`, "lower this first if perf drops") is only
   applied in the normal spawn loop, which awareness switches off (`:1658`); objective and
   extraction waves come on top. `docs/STYLES.md` asks for at most 60 enemies.
   How sure: verified by reading; frame rate not measured. Fix: about 30, spawned a few per
   frame.

5. **Bots can walk off roofs and ledges, on Delta too.** A bot's new spot is 10-18 studs
   from the leader and is only checked with a level ray from the leader
   (`src/server/BotService.luau:189-198`); there is no check that there is floor under it,
   and the spot is kept after a teleport. The old spots were closer and directly behind.
   Trigger: stand still on a rooftop or tower with bots: a bot walks off towards its spot,
   comes back, and walks off again. How sure: verified by reading; needs a look in game.
   Fix: require floor near the leader's height before accepting a spot.

6. **Waves on Mile 14 can give up and stand around.** An Infected that starts in "chase"
   without ever having seen a soldier (every wave spawn, and one woken by being shot from
   far away) forgets after 8 s if it has no line of sight, then "searches" the spot it is
   standing on (`EnemyService.luau:1030-1031`). At night it only sees about 50 studs.
   Trigger: wound one with the sniper from 80 studs; or let an objective wave lose sight of
   you behind buses or brush. This contradicts the PR's own doc ("an objective's or a
   pallet's waves still come chasing"). How sure: verified by reading.
   Fix: remember the attacker's position on a hit, and fall back to the nearest soldier.

7. **Bushes stop bullets as well as sight.** To let brush hide you, the bush is made visible
   to every server ray (`src/shared/MeshAssets.luau:1435`), so players' and bots' shots stop
   at it too, and a standing soldier is hidden as well as a crouched one. Decide if that is
   wanted. Fix if not: test brush only in the Infected's sight check.

8. **The lobby's EDIT screen can be left stuck on screen.** `src/lobby/client/
   LoadmasterUI.luau:227-229` opens it without keeping a way to close it, and closing the
   Loadout underneath (`:175-178`) does not close it: a dark full-screen cover stays up and
   Backspace stops working. Triggers: gamepad B with EDIT open; resetting your character
   with EDIT open. How sure: verified by reading. Fix: keep the close function and call it
   when the Loadout closes; also bind gamepad B in the EDIT screen.

9. Smaller things:
   - Air strikes (Hammer, Anvil, Shrike) make no "noise" for awareness
     (`AirStrikeService.luau` never calls `EnemyService.noise`), so a strike only wakes
     what it wounds.
   - "Crouching" for detection is what the player's machine says
     (`src/server/StanceService.luau:170`); a cheater can claim it while running. Darkness is
     also not a real handicap for players: night vision is a screen effect anyone can use.
   - On the shotgun, the suppressor sits higher than the iron sights and covers the target
     when aiming in first person (`Config.luau:929`, width 0.28). Fix: a narrower can.
   - The suppressor is free: it is not bought or owned like guns
     (`Rules/Record.allows` does not look at attachments). A design choice to make.
   - The suppressor's name is written into the code in three places instead of on a row
     (`WeaponDefinitions.luau:317-325`); a second barrel option would be treated as one.
   - CI does not build the new `mile14.project.json`; `AGENTS.md` still lists two projects.

10. **Decision: this is a different Mile 14 from Tien's proposals.** Tien's #26 (Mile 14
    v2, draft) and its design page say the first layout "had 7 placement breaks" and that
    the mission goes in the game only after the objective pools work on Delta. Nova's map
    builds that first layout and ignores #26. The two also invent overlapping ideas
    (#26's sleeping "Possum" and Nova's sleeping Infected). Tien and Nova need to agree on
    one plan.

Checked and fine:
- **Checkpoint Delta's difficulty is unchanged**: awareness is switched on for Mile 14 only
  (`Config.Awareness.Missions`), and the night sky too. Bosses ignore awareness.
- Suppressor, cheat checks (read end to end): the lobby server checks every attachment
  against the list allowed for that gun; the match checks again with the same rule and does
  not trust what it is sent; the quieter shot is worked out from the server's own record of
  what is fitted, not from anything the client says. Old saved loadouts still load, and the
  lobby and match can be published in either order (no repeat of #16's problem).
- Noise and sight are cheap: one distance check per Infected per shot; each Infected looks
  about three times a second. Sight and hearing consider every living squad member and bot.
- An Infected cannot get stuck asleep: any hit, nearby shot, blast, running feet or a
  soldier within 3.5 studs wakes it.
- Trees and brush are within the collider and triangle budgets; no new lights.
- The awareness and bot-formation rules are pure with test files. `docs/OWNER.md` and
  `AGENTS.md` are not changed by these commits.
