# PR #27: Hocker spit: rearing tell, wobbling bile glob, splat, readable pool

- Author: tiennguyen03 (branch `claude/hocker-spit`)
- Head commit reviewed: `48f61c4a7a8013643911c62c93c9a88676d9a43d`
- Reviewed: 2026-11-11 (by reading the code; the tests were not run here)

**Verdict: Fix first** (no crash and the damage is unchanged, but the main new warning sign
very likely does not show, and a splat hangs in the air after a direct hit).

## What it does

The Hocker's spit gets a new look drawn on each player's machine: the head rears back before
it spits, the glob wobbles in flight, it splats, and the acid pool is easier to read. The
server still decides the flight, the hit and the pool damage exactly as before.

## Findings

1. **Very likely: the head never rears back, so the warning before a spit is only a few
   drips.** `src/client/SpitFX.luau:638-639` looks for the neck joint as a `Motor6D` (the
   old kind of joint). But the Infected bodies are rebuilt at spawn:
   `src/shared/MeshAssets.luau:1437-1442` destroys every `Motor6D` and rebuilds the rig, and
   `assets/3d/README.md` says rebuilt rigs use the newer `AnimationConstraint` joints. So the
   joint is not found and the tilt code at `:665` never runs.
   Trigger: any normal Hocker winding up. How sure: the code path is verified by reading;
   which joint type the engine really creates was not run here, so: very likely.
   `docs/STYLES.md` and the handoff say "the head goes back 16 deg", which would be wrong.
   Smallest fix: handle the `AnimationConstraint` case the way `StanceService.liftRig`
   already does (tilt the joint's attachment and put it back afterwards). Needs a playtest.

2. **A direct hit on a player or bot leaves a splat floating in the air for 2.5 s.**
   The server reports the hit with the surface direction of whatever was hit, bodies
   included (`src/server/EnemyProjectileService.luau:290-299`). A body's side counts as a
   "wall", so the client sticks a 3-stud blotch there (`SpitFX.luau:697-702`). The blotch
   does not move, so it hangs in the air when the player steps away. The spit is aimed at
   the middle of the body, so this is the common case.
   Trigger: stand still in front of a Hocker, take the hit, step aside.
   How sure: verified by reading. Smallest fix, on the server before calling `impact`:
   ```lua
   local normal = hit.Normal
   local model = hit.Instance:FindFirstAncestorOfClass("Model")
   if model and model:FindFirstChildOfClass("Humanoid") then
       normal = Vector3.yAxis -- a body is not a wall: draw the ground pool only
   end
   impact(spit, hit.Position, normal)
   ```

3. **Decision for the owner: the Warden's gas canister now looks like Hocker bile.**
   The Warden fires its canister through the same code (`src/server/IndexService.luau`,
   `Canister.Projectile`), and the new look is one global setting
   (`Config.Enemies.SpitFX`) that ignores each projectile's own colour. The PR's note says
   this is intended. It also goes against the project rule that per-item values live on the
   item's own row. Fix if unwanted: an optional look on each projectile's row.

4. Small: the old, green spit colours are still in `Config` (Hocker `Projectile.Color`
   190,215,60; canister 156,170,72). They still tint the Hocker's throat sac and come back
   if the new look is switched off. The owner's rule is "no zombie green". All the new
   colours are amber, brown and dark red; the pool's bubbles (206,186,112) are a pale
   yellow worth a look.

5. Small, docs: `docs/STYLES.md` has a budget of "nine emitters in the whole scene"; this
   PR adds nine more (they only fire in short bursts). The real cost is small; the wording
   needs a decision.

6. Small: a Hocker killed mid wind-up keeps dripping from its head for up to 0.8 s; a
   player who joins late does not see pools that are already down (4-6 s) but is hurt by them.

Checked and fine:
- The new message only goes from server to players. Damage rules are unchanged: every
  player and bot in a pool takes damage, downed bodies do not.
- The pool drawn matches the pool that hurts (same centre and radius).
- A run restart clears every glob, pool and splat on both server and players' machines.
- Parts are reused from a pool; no lights or decals; worst case about 50 parts and capped
  drip rates. Pause freezes it correctly.
- A Hocker that is too far away to be loaded on your machine is handled without errors.
