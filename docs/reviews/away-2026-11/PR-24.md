## What it does

It puts the remade bodies of the four common Infected into the game (45 new body-part
meshes). One switch, `Config.Enemies.BodyVersion`, chooses the new bodies (2) or the old
ones (1).

## Findings

No confirmed bug. Only 3 code files change; nothing touches players' messages, per-player
data or per-frame work.

1. **Possible: the Brute is wider and taller and may snag in doorways.**
   `src/shared/MeshAssets.luau:1172-1175`: the new Brute chest is 3.29 x 3.40 studs
   (old: 2.86 x 3.11, `:943-946`). The Brute is drawn at double size, so its solid chest
   goes from 5.7 to 6.6 studs wide and its top rises about 0.6 studs. `docs/LEVELS.md` says
   the Brute only just fits some rooms.
   Trigger: a Brute walking through the Shed's doors or a depot aisle.
   How sure: sizes verified by reading; whether it really snags needs a playtest.
   Fix if it does: trim the shoulder growth in the generator (`assets/3d/build/infected_v2.py`).

2. **Small: if a new mesh fails to load, that Infected shows up as a plain green Roblox
   figure.** With the new bodies on, the old ones are not prepared at all
   (`MeshAssets.luau:1550, 1571`), so there is no automatic fallback to them; the bare figure
   is painted with the form's colour (`EnemyDefinitions.luau:67`, Walker 88,154,84: the
   "zombie green" the owner banned). `main` behaves the same way when an old mesh fails, so
   this is not new. The manual fallback is `BodyVersion = 1`.

3. Small: the triangle limit is not checked for the new bodies in a normal asset build
   (`assets/3d/build/build_assets.py:2310-2314` checks only the old ones). The recorded
   counts are within the limits: Walker 1,792 of 1,800 (only 8 to spare), Runner 2,100 of
   2,200, Brute 2,088 of 3,000, Hocker 1,632 of 2,200.

4. Trivial: a comment in `MeshAssets.luau` says the old set has 39 meshes; it has 40.

Checked and fine:
- Body parts keep their names and joints, so headshots, dismemberment and stumps find the
  same parts. The Warden is not remade and still uses its own body.
- Both settings of the switch read correctly; the only code change in behaviour is where the
  Hocker's throat sac is attached.
- Body scale, spawn height and attack range are unchanged, so melee reach is as before
  (see PR-23.md finding 1, which depends on body height: still applies, unchanged).
- Same number of parts per Infected (15). No new colours in code; the generator uses the
  palette, with green only in the Hocker's throat and sac.
- The art comes from the generator script, not hand-edited files.
