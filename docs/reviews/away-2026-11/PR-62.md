## Findings

1. Fine: still no file under `src/` or `tests/` changes; the pieces only build with
   `--carrier-v2` (`assets/3d/build/build_assets.py`).
2. **Still over the drawing budget**: the ship measures about 49,500 triangles against today's
   16,600 and the 18,000 ship cap in `docs/STYLES.md` (plus a 24,000-triangle city). Cuts are
   listed, none decided. Run the performance-reviewer before approving.
3. **Repository size, now worse.** The 62 previews (76 MB) were all rendered again, and 11
   `vendor_*` pictures (about 15 MB) were added. Git keeps every old version, so this branch now
   adds roughly 165 MB of pictures to the project's history for everyone who clones it, even if
   the look is rejected. Smallest fix: keep a few before/after pairs in the repository and the
   rest on the Desktop folder only, and squash the branch before merging.
4. **A real-world content question (the doc asks it too):** the sapper sergeant holds a lit
   cigarette (`docs/sprints/CARRIER_V2.md:200, 206-209`). Roblox's rules restrict showing
   tobacco, depending on the experience's content maturity setting. Check that before building it;
   the doc's fallback (an unlit one behind the ear, a toothpick, or a tin mug) avoids the question.
5. Small (still open): `.gitignore` does not list `assets/3d/carrier_v2.blend`, which the
   script saves (`assets/3d/build/carrier_v2.py:46`). A `git add -A` would commit a large file.
6. The step list now includes lobby code steps for Nova (9b: move the Quartermaster's feet and
   two counters; 9c: delete the map room walls). Step 9c is already done by #67, so it should
   point there.
