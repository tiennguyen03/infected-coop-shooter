## What it does

It proposes a rebuilt Checkpoint Delta, in Blender only: a highway through a gate, an
outside area and a base behind it, with two- and three-storey buildings, a footbridge and
rebuilt vehicles (bus, humvee, plus a new SUV and ambulance). It comes with 41 preview
pictures and a design page, `docs/sprints/DELTA_V2.md`, that ends with questions for the owner.

## Findings

1. Fine: no file under `src/` or `tests/` changes. The new pieces are only built when the
   asset build is run with `--delta-v2`, so a normal build produces nothing new and the
   current map (`Missions/Delta.luau`) is untouched.

2. **Everything that makes a map playable is still to do**, by the author's own note:
   colliders, enemy spawns, pathing, lights and frame rate were not checked in Studio, and
   the `--delta-v2` build was not run from start to finish. Multi-storey buildings are new
   for this game: bots cannot jump or climb (see `PR-22.md` finding 3), Infected climbing
   has height limits, and the Brute only fits tall rooms (`PR-24.md` finding 1). Those need
   an answer before this layout is adopted.

3. **It would move the ground under several open pull requests.** #37's objectives use
   fixed sites and positions on today's Delta, #20's dev teleports are fixed coordinates,
   and #22's bot pathing was written for the flat map. Adopting v2 means redoing those
   positions.

4. Size: about 16 MB of preview pictures.

5. Small: the same one-line change to `build_assets.py`'s `--only` option as #17 and #19.
