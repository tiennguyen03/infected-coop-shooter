## What it does

Every lobby seller (Quartermaster, Call-ins, Vehicles) now opens the same kind of full screen as
the Loadmaster's loadout screen: a list of items, the picked one turning in 3D, its stats and a
BUY button. The shared parts of the loadout screen were moved into a new `KitView` file so the
match's loadout screen and the lobby desks use the same code.

## Findings

1. **The call-in pallets (#61) and the Arms Room's gun rack camera can no longer be reached**
   (sure; intended, but not asked). With the new screen on (`Config.Lobby.DeskScreen.Enabled =
   true`), choosing option 1 opens the screen first (`src/lobby/client/DeskDialogUI.luau:120-131`),
   so the pallet camera from #61 (line 134) and the rack camera
   (`ArmsRackUI.luau:792-813`) only run when the new screen is turned off. The BACKLOG row
   asks Tien only about the gun wall, not the pallets. The sapper sergeant still says "It's all
   laid out behind me…" (`src/lobby/shared/LobbyDesks.luau:148`), and
   `docs/sprints/LOBBY_V1_FALLOW.md` lines 103 and 516 still describe the old views. Decide
   which you want; then fix the line and the doc.
2. **More text too small on phones** (sure about the arithmetic). The phone layout is shrunk to
   about 0.62, and the desk screens always show section headers (size 14 →
   about 8.6 pixels; `src/lobby/client/DeskScreen.luau:296`), badges (15 → 9), the BACK hint and
   the seller's line (16-17 → 10-10.5). `docs/STYLES.md` asks for at least 11. Same issue as the
   loadout screen in `PR-59.md`, now on more screens. Fix: bigger sizes in `KitView.COMPACT`,
   or hide the headers on phones.
3. Small: Enter can buy a different item from the one you picked. It buys the row under the mouse
   first, then the picked one (`DeskScreen.luau:189-191, 304-309`). The panel does show the hovered
   item, so it matches what you see, but it surprises. Fix: Enter buys only the picked item.
4. Possible: the seller's line (410 × 56 box, size 17, wraps without cutting) can run to three
   lines on a phone and overlap the list (`DeskScreen.luau:135-137`).
5. Possible: after Back, the talk option you clicked may stay highlighted
   (`DeskTalk.luau:54-65`).
6. Not changed here, still open from `PR-59.md`: the Doorman's damage shows as 20, and the
   match's loadout screen shows "[B] BACK" with no controller B bound.

Fine: nothing is lost in the move to `KitView` (same layouts, stats, spin, and clean-up when
the screen closes). It works in both places (the match maps all of `src/client`; the lobby
project maps `KitView` beside `LoadoutMenu`). Buying still goes through the server's buy check;
the server change is a comment only. Each player's screen is their own, so four can shop at
once. The new rule `DeskOffer` has tests.
