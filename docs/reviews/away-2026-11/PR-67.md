## What it does

In the lobby ship, the map room ("THE PLOT") had walls and a narrow door that were awkward to get
through with a full squad. This PR removes the walls so the map table is open floor reached
from any side, puts the board on two posts of its own, and renames "THE PLOT" to "MAP ROOM" in
what players see.

## Findings

1. Nothing still uses the removed door numbers (`doorZ0`, `doorZ1`) or the old `plotter`
   position (searched the whole branch).

   (`src/lobby/server/PlotService.luau:71-92`), on the floor, using the board's own size from
   `FallowLayout.Board`. They only add 4 small parts.

   `plot`) while players read MAP ROOM. Fine for now (renaming ids would touch saves and
