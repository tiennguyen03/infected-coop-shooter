## What it does

Your soldier speeds up and slows down smoothly instead of starting and stopping instantly
("momentum"). This PR moves the few lines that work that out each frame from
`MomentumController` into a shared rule, `Rules/Momentum`, with seven tests. The game feels the
same.

## Findings

No bugs found.

- `Momentum.moveToward` (`src/shared/Rules/Momentum.luau:10-17`) is the old function word for
  word, and `Momentum.step` (lines 22-36) is the old block from `MomentumController.step`
  (choose speed-up or slow-down rate, ease toward the target, cap at the current walk speed).
  The controller passes the same values (`src/client/MomentumController.luau:86-89`), and
  nothing else in the file still calls the deleted copy.
- The tests use Lune's Roblox `Vector3`, as `tests/Sight.spec.luau` already does, and check
  speeding up, slowing down, turning back, the speed cap and standing still.
