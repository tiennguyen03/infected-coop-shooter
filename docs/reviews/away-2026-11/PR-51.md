## What it does

"Bloom" is how a gun gets less accurate while you hold the trigger and recovers when you
pause. This PR moves that small calculation from the server's shooting code into the shared
rule file `Rules/Spread`, and adds four tests. The numbers and the behaviour are the same.

## Findings

No bugs found.

- The new function (`src/shared/Rules/Spread.luau:29-41`) does the same steps in the same
  order as the old lines: cap the carried bloom at this gun's maximum, take off what the
  pause earned (never below zero), fire with that, then add one shot's worth (never above
  the maximum).
- `src/server/ProjectileServer.luau:393-403` passes the same per-gun values
  (`BloomMax`, `BloomRecovery`, `BloomPerShot`) and stores the result as before. This is
  inside the server's shot check, and none of the checks around it change.

## Check in Studio

1. Hold the trigger on the M249: the spread should grow and stop growing at the same point
   as before; pause and it should tighten again.
2. Fire until the spread is wide, swap to the pistol and fire: the pistol should not be
   wider than its own maximum.
