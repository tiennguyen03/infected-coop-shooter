# PR #68: Hocker spit pool looks like a puddle, not a circle

- Author: tiennguyen03 (branch `claude/spit-puddle`)
- Head commit reviewed: `b548f10e9ef79930e92b68fa0f13ea2297c203fd`
- Reviewed: 2026-11-18 (by reading the code; the tests were not run here)

**Verdict: Fix first** (two small Config changes so the puddle you see matches where it hurts).

## What it does

When a Hocker (the spitter) or the Warden's canister leaves an acid pool, it used to look like
a flat circle. Now it spreads out as an uneven puddle of blobs with a dark rim and a wet shine,
then shrinks and fades at the end. Only the look changes; damage is still worked out on the
server.

## Findings

1. **You can get hurt where there is no puddle** (sure about the numbers). The server hurts
   everyone inside a full circle of the pool's radius
   (`src/server/EnemyProjectileService.luau:373-376`). The new puddle only promises to cover
   about three quarters of that radius in every direction (the core is 0.84 × 0.92 of the
   radius, `src/shared/Config.luau:2589-2590`; the test checks 0.75). In the dips between
   blobs there can be about 1 stud of bare ground that still hurts for a Hocker pool (radius 6),
   and about 2 studs for the Warden's (radius 9). Players will feel cheated. Smallest fix: raise
   `CoreSize` to about 0.95 (and the test's 0.75 to 0.9), so the liquid reaches the edge.
2. **In its last second the puddle shrinks while still hurting at full size** (sure).
   `SpitShape.pool` shrinks it to 70% over the last second
   (`src/shared/Rules/SpitShape.luau:56`, `Shrink = 0.3`, `Fade = 1`), but the server keeps
   the full radius until the pool ends. Together with finding 1, the visible edge can be at
   about half the radius while the whole circle still hurts. Fix: `Shrink = 0`, or make the
   server's radius shrink the same way.
3. Docs say a pool is 14 parts (`docs/STYLES.md` §8, the `SpitFX` header line 16, the handoff
   log); it is 15 (7 blobs, 7 rims, 1 shine; `src/client/SpitFX.luau:518-530`). At the limit
   of 8 pools that is 120 parts, up from 16.
4. Possible: each of those parts is a sphere mesh; nobody measured the triangles with 8 pools
   out. Check the render stats in Studio.
5. Small: the new test uses its own copy of the shape settings, not Config's, so changing
   Config is not covered. At least add a comment linking the two.

Fine: parts are reused and all removed on reset; the shaping only runs while a pool grows
or fades, not every frame for a settled pool; no server file uses the changed rule;
`--!strict`, Config values and tests are in place.

## Check in Studio

1. Spawn one Hocker, let it spit, stand in a gap between two blobs near the edge: do you take
   damage with no liquid under you (finding 1)?
2. Stand near the edge in the pool's last second: do you get hurt after it has visibly
   shrunk past you (finding 2)?
3. Several Hockers plus the Warden's canister (8 pools): check the render stats.
4. On dark ground: does the rim read, and do the blobs look like one liquid?
