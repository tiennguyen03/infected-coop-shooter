## What it does

It puts every keyboard key of the match in one table, `Config.Keys`, and changes six of
them. All the hints on screen now read that table, and two tests fail the build if two
actions share a key or a key is written anywhere else.

| Action | Before (`main`) | After |
|---|---|---|
| Interact / revive (hold) and lobby desk "Talk" | F | E |
| Stim | E | V |
| Shove | V | F |
| Crouch | Left Ctrl | C or Left Ctrl |
| Prone | C | Z |
| Supply flare | 5 | X |
| Roll, slide | sprint + Left Ctrl, sprint + C | unchanged here (see #38) |
| Sprint, vault, swap, grenade, reload, call-ins, Arms Room, camera | Shift, Space, Q, G, R, 1-4, B, T | unchanged |

## Findings

1. **Decision: please confirm the owner chose these keys.** `docs/OWNER.md` on `main` says
   the keys were fixed on 2026-11-08 and "Do not change the bindings without them". This PR
   replaces those lines with a new table marked `(2026-11-11, "do it")`. This review cannot
   tell whether Tien said that. If yes, fine. If not, this PR should wait.

2. **This PR and #38 disagree on roll and slide until both are merged.** Here sprint + Left
   Ctrl still rolls and sprint + C still slides (`src/shared/Config.luau:25-27`); in #38 roll
   is Shift twice and both keys slide. They agree on everything else (C/Ctrl crouch, Z
   prone). A trial merge conflicts in `MovementController.luau`, `StanceController.luau`,
   `Config.luau` and five docs. After merging, #38's keys written directly in code will fail
   this PR's "no keys outside Config.Keys" test until they are moved into the table.
   How sure: verified by reading both. The PR's own note gives the plan: keep #38's roll and
   slide, keep #40's key table, remove `Keys.Roll` and `Keys.Slide`.

3. **Possible: you can now drop prone from a full sprint, and during a roll or slide.**
   `src/client/StanceController.luau:125` only skips the roll and slide keys while
   sprinting; Z (prone) is not skipped (`:134-135`). On `main` both stance keys were ignored
   while sprinting.
   Trigger: hold Shift + W and press Z; or press Z during a roll or slide: the body may
   travel prone at roll speed until the move ends.
   How sure: the code path is verified; how it looks needs a playtest.
   Smallest fix if unwanted: also ignore Z while sprinting or while a roll or slide is active.

4. Small, stale text the new test cannot catch: `Config.luau:858` ("the flare is key 5"),
   `.claude/agents/systems-designer.md:16-17` (the design agent still reads the old keys),
   and three lobby comments that say the Talk prompt is "(F)".

5. Heads-up for Nova: one lobby line changes
   (`src/lobby/server/DeskService.luau:132`, F becomes `Config.Keys.Interact`). Lobby players
   must press E at desks, and the lobby place must be republished for it to apply.

Checked and fine:
