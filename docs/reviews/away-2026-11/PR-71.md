# PR #71: ATV: Nova's own model (body) on built wheels, painted to Nova's colour reference

- Author: MatthewDuke04 (Nova) (branch `nova/vehicles-atv`)
- Head commit reviewed: `5020b1e7a5d7e70df4884718e333ad5def6502cb`
- Reviewed: 2026-11-18 (by reading the code; the tests were not run here)

**Verdict: Needs a decision** (the model is about twice the triangle limit, by an exception
Nova wrote in; that is the owner's call. Also a few small fixes.)

## What it does

The ATV (merged earlier in #65) was built from blocks. This PR gives it Nova's own sculpted
body as a 3D model, on four modelled wheels, painted to Nova's colours. The driving code is
unchanged.

## Findings

1. **Over the triangle limit, by its own exception** (sure). The body is about 7,950
   triangles plus 4 wheels of 564, about 10,200 per ATV, against the 5,000 cap for vehicles in
   `docs/STYLES.md` (line 324). STYLES now carries "Budget exception (Nova, 2026-11-17)" (line
   624). A hard cap exception should be Tien's decision; add it to the BACKLOG "Your call" list.
   Nova's log says the phone frame-rate check was not done; do it before keeping it. Docs also
   disagree on the number ("~12k" in HISTORY, the handoff and the STYLES headline; 10,202 in the
   STYLES detail).
2. **The fallback block body no longer fits** (sure by the coordinates; only seen while the 3D
   model has not loaded yet, or if it fails). The seats moved for the new model, but the block
   body that stands in until then was not changed (`src/shared/VehicleBody.luau:347` onward).
   The driver sits inside the fuel tank block, the gunner inside the back cushion, and the
   wheels can poke through the fenders. Trigger: call an ATV in the first seconds after a
   server starts. Fix: lower those blocks about 1 stud, or make the fallback a plain box.
3. **Blender's backup file is committed** (sure). `assets/3d/arena_survivor.blend1` is a
   backup Blender writes on its own (already tracked on main); this PR grows it from 100 KB to
   300 KB. Fix: add `*.blend1` to `.gitignore` and stop tracking that file. (Committing the
   `.blend` itself and the trimmed `atv_body.obj` source follows the project's existing practice.
   The 70 MB original is correctly ignored.)
4. Possible: an ATV lowered on the sling right after a server starts can show the block body in
   the air and then switch to the 3D model when it lands (`VehicleBody.luau:219-235` waits for
   each mesh up to 30 s; the client does not wait). In the lobby, the motor pool may stay empty
   for up to a minute if the meshes fail to load.
5. Possible: the invisible collision box (6.6 long) is shorter than the visible model
   (7.55 long), so the nose and tail can poke about half a stud into walls.
6. None of the findings in `PR-65.md` (the first ATV review: double damage with two riders,
   landing inside things, bot boarding, and so on) are fixed here, and #65 is already merged
   into main. They still need doing.

Fine: everything the driving code depends on is kept: seat types and names, wheel parts
with their attributes, the invisible "Chassis" as the root, the look-only pieces with collision
off, and the spring numbers match the new height.
