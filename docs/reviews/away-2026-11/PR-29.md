## What it does

It adds `docs/BACKLOG.md`: one plain-words page for the owner listing what is built and
waiting to be played, what is being built, what needs a decision, and what comes later. It
also adds a rule to `AGENTS.md` that work must update this page.

## Findings

1. **The page is already a little out of date.** It was written before #40, #41, #42, #45
   and #46 existed: "Building now" still lists the key layout (now #40) and the Delta
   revamp (now #41), and the "Try it" table has no row for #40, #42, #45 or #46.
   Smallest fix: add those rows when merging.

2. **Decision: one more always-updated page.** `AGENTS.md` already asks every change to
   update `handoff/README.md`, `docs/HISTORY.md` and the feature's doc, and says to "state
   each fact once" and keep docs short. This adds a fourth place, and much of its content
   repeats `handoff/README.md` and `docs/ROADMAP.md`. It is clearly useful to read on a
   phone; the cost is that it will drift unless every pull request keeps it up. The owner
   should decide whether this replaces the "Open work" table in the handoff or sits beside it.

3. **Things on the page that these reviews change:**
   - It says several pull requests "touch the same files; Claude joins them at merge time".
     The real conflicts are listed in the summary of pull request #43.
   - "Your call" item 6 (one key for crates and revive) is the clash described in
     `PR-36.md` and `PR-40.md`.
   - "Decided 2026-11-11 ... the Open Cloud key stays": `handoff/README.md` on `main` still
     lists "rotate the group Open Cloud key (it was pasted in chat)" as housekeeping. A key
     that was pasted into a chat should be treated as leaked. This is a security choice for
     the owner to make knowingly, not a detail.

4. Small: the page tells the owner how to play everything at once ("Rojo on port 34874 (the
   test mix)") and warns "Do not press Publish in a Studio window connected to the test
   mix". Good advice; it matters more now that #46 targets `main` with the test mix inside.
