## What it does

It proposes a second, bigger layout for the next mission, Mile 14 (a six-lane highway,
weigh station, toll plaza, a skyline), built in Blender, with preview pictures to compare
with the first version. It also contains the first version's design work (it is built on
the `claude/mile14` branch). Nothing in the game changes.

## Findings

1. **Performance is the open risk.** The author's note gives 201,000 triangles in play
   against 54,000 for the first version (about 3.7 times), and says frame rate, colliders,
   pathing, spawns and lights were not checked. The project's first rule is "smooth on
   low-end devices". Before this layout is adopted it needs a measured test in Studio, or
   the smaller option the backlog suggests (v2's skyline on v1's frame).

2. **Unlike the other proposals, this one changes what a normal asset build produces.**
   `assets/3d/build/build_assets.py` now always loads two new scripts (`driver.py`,
   `highway.py`) and adds two new body types to the triangle-limit table (`possum`,
   `driver`); 48 exported model files are added under `assets/3d/export/`. The other three
   proposals hide their work behind a build flag; this one does not. None of the new pieces
   is in `MeshAssets` or uploaded, so the game itself is unaffected.
   How sure: verified by reading the build script's diff.

3. **Size: about 42 MB of new binary files** (132 files: previews, two `.blend` files,
   exported models). That is a lot to add to the repository for a proposal; consider
   keeping the pictures elsewhere if the layout is not chosen.

4. It also adds a new Infected ("Possum") and a boss body ("driver") to the build script.
   Those are new game content with no design decision recorded in `docs/PROGRESSION.md`
   on `main`; approving the map should not silently approve them.

5. Known from the author's notes: some wrecks clip into the median wall and the fields are
   empty. The owner's rule is "nothing clips or flickers".
