## What it does

In first person, each gun now lines up its own sights from values on that gun's `Config`
row. The three scoped guns (M2010, M110, the Goose) really zoom (6x, 3.5x, 3x) and show a
scope picture drawn in code. Reloading and swapping guns lower the sights.

## Findings

1. **Heads-up for Nova: this replaces parts of Nova's "Real sights on every gun" from
   2026-11-10.** Nova last worked on `CameraController`, `FirstPersonView`, `MeshAssets`,
   `PlayerSetup` and `guns.py`. This PR removes the sight point from `MeshAssets`
   (`sight`, `getSight`), the `Sight` part on the gun Tool, and four values under
   `Config.Camera.FirstPerson`, and puts per-gun `Sight` rows in their place. Nothing else
   still reads the removed pieces (checked). Nova's own note asked for the scopes to get
   "real work", which this does, but Nova should see it before it merges.

2. **Merging with #28 (binoculars) can silently break the binoculars.** Both PRs use a
   variable called `scoped` in `src/client/CameraController.luau`: #28 as a module-wide
   "binoculars are up" flag (#28's line 70), this PR as a local "this gun has a scope" value
   inside the per-frame function (`:277`). If both sides are kept when resolving the
   conflict, #28's binocular line reads this PR's value instead: the binoculars would never
   raise, or would raise by themselves when a scoped gun is held in first person. The
   automatic checks would not catch it.
   How sure: verified by reading both branches; a trial merge conflicts in exactly this file.
   Smallest fix, in whichever merges second: rename this PR's local to `gunScoped` (4 places).

3. Small: if you are already aiming in third person with a sniper and switch to first
   person (T), the scope appears instantly with no raise (`CameraController.luau:150-160`
   does not reset the aim blend). Fix: set `adsBlend = 0` in `setFirstPerson`.

4. Possible: if your character is missing for a moment while scoped (falling out of the
   map, a run restart), the scope picture is removed but the view stays zoomed at up to 6x
   until the new body arrives (`CameraController.luau:265-268` returns before resetting the
   zoom). Fix: reset the field of view before that `return`.

5. Small: taking an ammo box right after pressing Q can make the gun dip twice
   (`src/client/FirstPersonView.luau:416-424`).

6. Small, project rule: a few timing numbers are written in code instead of `Config`
   (`src/shared/Rules/Sight.luau:129`, `CameraController.luau:378`).

Checked and fine:
- Every per-gun value is on that gun's own row, with a default; there is no list of gun
  names. A new gun with no `Sight` gets a safe default (and a test insists it has one).
- Nothing changes on the server: firing is checked exactly as before. Third-person aiming
  is unchanged.
- The zoom, the scope picture and the hidden gun are all restored on: weapon swap, reload,
  death, respawn, pause, and leaving first person.
- The scope picture is about 117 small frames built once, not per frame; no image assets.
- The crosshair in the scope is the true aim point.
