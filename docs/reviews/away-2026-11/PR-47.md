## What it does

It moves the small rules that decide when an Infected's arm or leg comes off (which body
part belongs to which joint, how much damage breaks it) out of `GoreService` into a shared
rule file with six tests. The numbers and the behaviour are the same.

## Findings

No bugs found.

- The four functions in `src/shared/Rules/Dismember.luau` are the old code moved as it was
  (`sideOf`, `jointFor`, `canSever`) plus `hit`, which does the same sum as before: add the
  damage, and when the total reaches the joint's share of max health, break it and mark it
  "spent" so it never breaks twice. A joint already spent stays spent (checked: adding
  damage to "minus infinity" still gives "minus infinity").
- `src/server/GoreService.luau` passes the same `Config.Enemies.Dismember` values as before.

## Check in Studio
