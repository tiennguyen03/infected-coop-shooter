## What it does

The F1 developer panel is reorganised into tabs (Run, Player, Infected, Guns, Call-ins,
Upgrades, Teleport) with new hotkeys F8 and F9. Squadmates and bots get a thin pale blue
outline you can see through walls, yellow while they are downed.

## Findings

1. **Possible: a squadmate's outline can disappear after they walk far away and come back.**
   `src/client/AllyOutline.luau:46-54`. The outline is added when a player's soldier first
   appears (`CharacterAdded`). The match place uses streaming (`default.project.json`:
   `StreamingEnabled`, radius 384 studs): far-away models are removed from your machine and
   sent again when you get close. When the soldier is sent again, `CharacterAdded` does not
   fire a second time, so the outline (which only exists on your machine) may not come back.
   Bots are fine: they are picked up by `folder.ChildAdded` each time they arrive.
   Trigger: two players, walk more than about 400 studs apart, walk back.
   How sure: possible, not confirmed (needs a 2-player test; the PR's own note lists this as
   unchecked). Smallest fix, in `AllyOutline.init()`:
   ```lua
   workspace.ChildAdded:Connect(function(child)
       local owner = Players:GetPlayerFromCharacter(child)
       if owner and owner ~= Players.LocalPlayer and child:IsA("Model") then
           outline(child)
       end
   end)
   ```
   (`outline` already skips a soldier that has one.)

2. **Possible: the new F9 hotkey ("Warden in front of me") also opens Roblox's developer
   console.** `src/client/DevTestPanel.luau:330`. F9 is Roblox's built-in key for the
   developer console, so one key press would do both. How sure: possible (the key is
   Roblox's default; whether the game also receives the press was not tested). Smallest fix:
   use another free key (for example F10) or drop the hotkey.

3. Fine: the server still refuses every dev command unless it is Studio or the creator's
   account (`src/server/DevTestService.luau:521-525`), and this PR does not change the
   server. All 32 commands the new panel sends exist on the server.

4. Fine: the outline uses one `Highlight` per squadmate (at most 3), far below Roblox's
   limit of 31 visible highlights. It reads the same `SquadState` attribute the rest of the
   HUD uses (`Squad.luau:88-90` sets it on the soldier), through `Attributes`, with colours
   in `Config.AllyOutline`.

5. Small: the teleport spots and the list of Infected forms are written inside
   `DevTestPanel.luau` (lines 50-62) instead of read from `Config` / `EnemyDefinitions`. They
   were already like this before; it only matters when a new Infected form or map is added.

## Check in Studio

1. Press F1: do all seven tabs fit and work in a small window?
2. Press F9 with the panel closed: does the Roblox console pop up as well as the Warden?
3. With bots: can you see the blue outline through a wall, and does it turn yellow when a

4. With a second player: walk far apart and back; is the outline still there?
5. Is the outline too strong or too faint? (`Config.AllyOutline.Transparency`)
