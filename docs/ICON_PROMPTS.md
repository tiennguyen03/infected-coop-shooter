# FABLE5_ITEM_ICON_PROMPTS.md

Create 2D vector-style game UI icons for a military zombie apocalypse roguelike.

General style requirements for all icons:

- clean vector art
- readable at small size
- strong silhouette
- game UI icon style
- slightly stylized, not overly realistic
- military / tactical aesthetic
- dark apocalypse tone
- simple background or transparent background if supported
- high contrast
- suitable for Roblox game UI
- each icon should feel polished and professional
- avoid excessive tiny detail
- square composition
- icon should be centered and easy to recognize instantly

---

## 1. Hollow Point Rounds

Prompt:

Create a clean vector-style game icon of hollow point bullets / tactical ammunition for a military zombie apocalypse game. Show a few stylized rifle rounds with aggressive pointed or hollow-tipped design, possibly with a subtle blood-red accent or torn-metal effect. The icon should feel dangerous, tactical, and readable at small size.

---

## 2. Adrenaline Injector

Prompt:

Create a clean vector-style game icon of an adrenaline injector / combat stimulant syringe for a military zombie apocalypse game. The syringe should look tactical and medical, with a glowing fluid or emergency stimulant vibe. The icon should feel urgent, intense, and easy to read in a game UI.

---

## 3. Tactical Drone Beacon

Prompt:

Create a clean vector-style game icon of a military drone beacon for a zombie apocalypse roguelike. Show a compact tactical beacon device with radio-wave signals and a small drone or drone silhouette implied in the design. The icon should feel high-tech, military, and support-focused.

---

## 4. Emergency Ammo Cache

Prompt:

Create a clean vector-style game icon of an emergency ammo cache / military supply box for a zombie apocalypse game. Show a tactical crate or supply box with ammo markings and a rugged battlefield feel. The icon should feel useful, rewarding, and strongly readable at small size.

---

## 5. Air Support Authorization

Prompt:

Create a clean vector-style game icon of an airstrike authorization / military air support command for a zombie apocalypse game. Show a targeting reticle, radio command symbol, or missile strike motif. The icon should feel powerful, high-impact, and like a top-tier offensive ability.

---
